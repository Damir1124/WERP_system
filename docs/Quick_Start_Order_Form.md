# Быстрый старт: Создание заказа с несколькими продуктами

## Как создать заказ за 30 секунд

### Шаг 1: Откройте форму создания заказа
Перейдите в админ-панель: **`/admin/logistics/order/add/`**

### Шаг 2: Введите данные клиента
```
📞 Номер телефона: +998901234567
📍 Адрес доставки:  Улица Навои, дом 15, кв. 42
👤 ФИО клиента:     Иванов Иван (опционально)
```

**Важно:** Если клиент уже есть в базе, система найдет его по телефону автоматически!

### Шаг 3: Добавьте продукты
1. Выберите продукт из списка (например: "Вода 19л")
2. Укажите количество (например: 3)
3. Нажмите **"➕ Добавить продукт"** для добавления еще одной позиции
4. Повторите для всех нужных продуктов

### Шаг 4: Настройте параметры
```
💳 Способ оплаты:    Наличные / Карта / Бонус
🚗 Курьер:           (можно оставить пустым)
📝 Примечание:       (опционально)
```

### Шаг 5: Сохраните
Нажмите **"Сохранить"** внизу страницы.

---

## Пример заказа

**Клиент:** +998901234567, ул. Навои 15, кв. 42  
**Продукты:**
- Вода 19л × 5 шт.
- Помпа для воды × 1 шт.
- Стаканчики × 2 упаковки

**Оплата:** Наличные  
**Примечание:** Позвонить за 30 минут до доставки

---

## Что происходит автоматически?

✅ **Клиент создается/обновляется** — по номеру телефона  
✅ **Цена рассчитывается** — product.price × quantity для каждой позиции  
✅ **Заказ попадает в пул** — курьеры видят его в боте  
✅ **При доставке списывается со склада** — через сигналы Django

## Частые вопросы

**Q: Что если я ввел неправильный номер телефона?**  
A: Форма автоматически форматирует номер в +998XXXXXXXXX. Если формат неверный, вы увидите ошибку.

**Q: Можно ли изменить заказ после создания?**  
A: Да! Откройте заказ в админке, измените продукты/количество и сохраните.

**Q: Как удалить продукт из заказа?**  
A: Нажмите кнопку **"🗑️ Удалить"** рядом с нужной позицией.

**Q: Обязательно ли указывать курьера?**  
A: Нет. Курьер может взять заказ сам из пула в Telegram боте.

## Горячие клавиши

- **Tab** — переход между полями
- **Enter** в поле количества — добавить новый продукт
- **Ctrl+S** — сохранить форму (в большинстве браузеров)
