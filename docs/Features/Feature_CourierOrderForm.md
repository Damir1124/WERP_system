# Форма создания заказа для курьера (Telegram Mini App)

## Описание

Реализована улучшенная форма создания заказов для курьеров в Telegram Mini App с поддержкой добавления нескольких продуктов и автоматическим созданием клиентов.

## Основные возможности

### 1. Информация о клиенте

- **Номер телефона** (обязательно) — автоматический поиск клиента в базе
- **Адрес доставки** (обязательно) — адрес куда везти заказ
- **ФИО клиента** (опционально) — если клиент новый

### 2. Несколько продуктов в одном заказе

- Динамическое добавление неограниченного количества позиций
- Для каждой позиции:
  - Выбор продукта из списка (с отображением цены)
  - Указание количества (stepper +/-)
  - Кнопка удаления позиции

### 3. Параметры заказа

- Способ оплаты (Наличные/Карта)
- Примечание к заказу (опционально)

### API Endpoint

**POST** `/api/bot/courier/orders/create/`

**Тело запроса:**
```json
{
  "trip": 123,
  "client_phone": "+998901234567",
  "client_address": "Улица Навои, дом 15, кв. 42",
  "client_name": "Иванов Иван",
  "payment_type": "CH",
  "note": "Позвонить за 30 минут",
  "items": [
    {
      "product": 1,
      "quantity": 5,
      "exchange_qty": 5,
      "sell_with_qty": 0,
      "defective_qty": 0
    },
    {
      "product": 3,
      "quantity": 2,
      "exchange_qty": 0,
      "sell_with_qty": 0,
      "defective_qty": 0
    }
  ]
}
```

**Параметры:**
- `trip` (int, обязательно) — ID текущего рейса курьера
- `client_phone` (string, опционально) — телефон клиента для поиска/создания
- `client_address` (string, опционально) — адрес доставки
- `client_name` (string, опционально) — ФИО клиента
- `payment_type` (string, обязательно) — тип оплаты: `CH` (наличные), `CD` (карта), `BS` (бонус)
- `note` (string, опционально) — примечание к заказу
- `items` (array, обязательно) — массив позиций заказа

**Ответ:**
```json
{
  "status": "created",
  "message": "Заказ создан",
  "order": {
    "id": 456,
    "client_name": "Иванов Иван",
    "client_address": "Улица Навои, дом 15, кв. 42",
    "client_phone": "+998901234567",
    "payment_type": "CH",
    "status": "PD",
    "total_price": 150000,
    "items": [...]
  }
}
```

## Использование

### Для курьера в Telegram Mini App

1. Открыть Mini App курьера
2. Перейти на вкладку "Пул"
3. Нажать кнопку **"+ Оформить заказ"**
4. Заполнить данные клиента:
   - Ввести номер телефона (автоматический поиск)
   - Указать адрес доставки
   - При необходимости указать ФИО
5. Добавить продукты:
   - Выбрать продукт из списка
   - Указать количество
   - Нажать **"➕ Добавить продукт"** для добавления еще позиций
6. Выбрать способ оплаты
7. Нажать **"Создать заказ"**

### Автоматические действия

✅ **Поиск клиента** — по номеру телефона в базе данных  
✅ **Создание клиента** — если не найден, создается автоматически  
✅ **Обновление адреса** — если клиент найден, адрес обновляется  
✅ **Нормализация телефона** — автоматическое форматирование в +998XXXXXXXXX  
✅ **Привязка к рейсу** — заказ автоматически привязывается к текущему рейсу курьера  
✅ **Расчет цены** — автоматический расчет стоимости каждой позиции  

## Валидация

### На фронтенде

- Обязательность телефона и адреса
- Минимум 1 продукт в заказе
- Все продукты должны быть выбраны
- Количество > 0

### На бэкенде

- Проверка существования продуктов
- Проверка принадлежности рейса курьеру
- Валидация формата данных
- Проверка наличия активного рейса

## Интеграция с другими модулями

### Связь с Clients

- Автоматический поиск клиента по телефону
- Создание нового клиента при необходимости
- Обновление адреса существующего клиента

### Связь с Logistics

- Заказ создается со статусом `PENDING`
- Автоматическая привязка к текущему рейсу курьера
- Создание позиций заказа (`OrderItem`)

### Связь с Warehouse

- При доставке автоматически списываются товары со склада
- Учитывается маппинг товаров

### Связь с Accounting

- При доставке создается финансовая транзакция
- Учитывается способ оплаты

## Отличия от админ-панели

| Функция | Админ-панель | Mini App курьера |
|---------|--------------|------------------|
| Доступ | Только администраторы | Все курьеры |
| Интерфейс | Django Admin | Telegram Mini App |
| Клиент | Выбор из списка | Поиск по телефону + автосоздание |
| Рейс | Выбор вручную | Автоматически текущий рейс |
| Назначение курьера | Вручную | Автоматически текущий курьер |
| Использование | Офис, диспетчер | В поле, на месте у клиента |
