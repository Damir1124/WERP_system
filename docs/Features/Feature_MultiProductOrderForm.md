# Форма создания заказа с несколькими продуктами

## Описание

Реализована улучшенная форма для создания заказов в админ-панели Django с поддержкой добавления нескольких продуктов в один заказ. Форма оптимизирована для быстрого и удобного создания заказов оператором.

## Основные возможности

### 1. Упрощенный ввод данных клиента

Форма автоматически определяет, существует ли клиент в базе данных по номеру телефона:

- **Если клиент существует**: его данные (адрес, ФИО) автоматически подгружаются
- **Если клиент новый**: он создается автоматически при сохранении заказа

### 2. Динамическое добавление продуктов

- Кнопка **"➕ Добавить продукт"** позволяет добавлять неограниченное количество позиций
- Каждая позиция содержит:
  - Выбор продукта из выпадающего списка (с отображением типа и цены)
  - Количество товара
  - Кнопку удаления позиции

### 3. Логический порядок полей

Поля выстроены в оптимальном порядке для быстрого заполнения:

1. **Информация о клиенте** (📞)
   - Номер телефона (обязательно)
   - Адрес доставки (обязательно)
   - ФИО клиента (опционально, если новый)

2. **Продукты в заказе** (🛒)
   - Список продуктов с возможностью добавления/удаления

3. **Параметры заказа** (⚙️)
   - Способ оплаты
   - Назначенный курьер (опционально)
   - Примечание к заказу (опционально)

## Использование

### Создание нового заказа

1. Перейдите в админ-панель: `/admin/logistics/order/add/`
2. Заполните данные клиента:
   - Введите номер телефона (формат: +998901234567)
   - Укажите адрес доставки
   - Если клиент новый, укажите ФИО
3. Добавьте продукты:
   - Выберите продукт из списка
   - Укажите количество
   - Нажмите "➕ Добавить продукт" для добавления еще одной позиции
4. Настройте параметры:
   - Выберите способ оплаты (Наличные/Карта/Бонус)
   - При необходимости назначьте курьера
   - Добавьте примечание
5. Нажмите "Сохранить"

### Редактирование заказа

При редактировании существующего заказа:
- Данные клиента автоматически заполняются
- Все добавленные продукты отображаются
- Можно добавлять новые позиции или удалять существующие

## Валидация

### Автоматическая валидация

- **Номер телефона**: автоматически форматируется в +998XXXXXXXXX
- **Минимум продуктов**: в заказе должен быть хотя бы один продукт
- **Количество**: должно быть больше 0

### Обработка ошибок

- Если номер телефона некорректный, выводится сообщение с подсказкой
- Если не добавлено ни одного продукта, форма не отправляется

## Автоматические действия

### При сохранении заказа

1. **Поиск/создание клиента**:
   - Система ищет клиента по номеру телефона
   - Если найден - обновляет адрес
   - Если не найден - создает нового

2. **Расчет цены**:
   - Для каждой позиции автоматически рассчитывается цена: `product.price * quantity`
   - Общая сумма заказа рассчитывается через `Order.get_total_price()`

3. **Инициализация полей тары**:
   - Для продуктов типа WATER/BOTTLE_20L автоматически устанавливается `exchange_qty = quantity`
   - Это стартовое значение для курьера при подтверждении доставки

## Преимущества новой формы

✅ **Быстрое создание**: все поля на одной странице, логично выстроены  
✅ **Гибкость**: можно добавить любое количество продуктов  
✅ **Автоматизация**: клиент создается автоматически, цены рассчитываются сами  
✅ **Удобство**: подсказки, валидация, красивый интерфейс  
✅ **Безопасность**: валидация данных на уровне формы и модели  

## Интеграция с другими модулями

### Связь с Warehouse

При сохранении заказа со статусом DELIVERED:
- Автоматически списываются товары со склада через сигналы
- Учитывается маппинг товаров (BOTTLE_20L → BOTTLE + WATER)

### Связь с Accounting

При доставке заказа:
- Создается финансовая транзакция (доход)
- Учитывается способ оплаты (наличные/безнал)
- Обновляется баланс смены курьера

### Связь с Bot Bridge

Созданный заказ:
- Может быть назначен курьеру
- Отображается в пуле заказов в Telegram боте
- Курьер может подтвердить доставку через бот
