# Telegram Bot — Интерфейс через кнопки в чате (без Mini App)

**Создан:** 2026-07-05
**Статус:** ✅ Реализовано (профиль «Курьер», 2026-07-12)
**Цель:** Определить, какие функции можно реализовать через обычные кнопки Telegram (Reply/Inline), а какие требуют Mini App

> 📌 **Курьерский поток полностью реализован кнопками** в `tg_bot/routers/courier.py`
> (смена → рейс → пул → взять → доставить с операциями по таре → закрыть).
> Mini App при этом **не удалён** — кнопка «🌐 Mini App» остаётся в главном меню.
> Детали реализации и FSM: [[Modules_CourierBot]].

---

## 1. Анализ текущей архитектуры

### Что уже есть в проекте:
- ✅ **Django API** (`apps/bot_bridge/`) — полный набор эндпоинтов для курьера, клиента, админа
- ✅ **Aiogram 3.x бот** (`tg_bot/`) — базовая структура с роутерами и middleware
- ✅ **Mini App фронтенд** (`frontend/courier/`, `frontend/client/`) — React-приложения
- ✅ **Модели данных** — `CourierShift`, `CourierTrip`, `Order`, `OrderItem`, `Client`, `Product`

### Текущая проблема:
Mini App требует:
- HTTPS (ngrok/домен)
- Сборку фронтенда (npm build)
- Знание React/JavaScript
- Сложную отладку

**Решение:** Максимально использовать нативные возможности Telegram (кнопки, текст, callback_data)

## 2. Что МОЖНО реализовать через кнопки в чате

### 2.1 Профиль «Курьер» — ЧТО ВОЗМОЖНО

#### ✅ **Управление сменой**
**Реализация:** Reply-кнопки + Inline-кнопки

```
Главное меню (ReplyKeyboard):
┌─────────────────────────┐
│  🟢 Открыть смену       │
│  🚀 Начать рейс         │
├─────────────────────────┤
│  📦 Пул заказов         │
│  🚚 Мой рейс            │
├─────────────────────────┤
│  📋 История смен        │
│  👥 Коллеги             │
└─────────────────────────┘
```

**Сценарий "Открыть смену":**
```
Курьер: [нажимает "🟢 Открыть смену"]
Бот: POST /api/bot/shifts/ → создаёт CourierShift
Бот: ✅ Смена #42 открыта!
     📅 Дата: 05.07.2026
     ⏰ Время: 08:30
     
     [🚀 Начать рейс]
```

**Сценарий "Начать рейс":**
```
Курьер: [нажимает "🚀 Начать рейс"]
Бот: Сколько полных баклажек загружено?
Курьер: 50
Бот: POST /api/bot/trips/ {full_loaded: 50}
Бот: ✅ Рейс #15 начат!
     🚛 Загружено: 50 шт.
     
     [📦 Взять заказ из пула]
     [📊 Статистика рейса]
     [🏁 Закрыть рейс]
```

**Вердикт:** ✅ **ПОЛНОСТЬЮ ВОЗМОЖНО** через FSM (Finite State Machine) aiogram

#### ✅ **Пул заказов (упрощённый)**
**Реализация:** Текстовые сообщения + Inline-кнопки

```
Курьер: [нажимает "📦 Пул заказов"]
Бот: GET /api/bot/courier/pool/

Бот: 📦 Доступные заказы (3):

     #127 | Иванов И.И.
     📍 ул. Навои, 15, кв. 42
     🚰 Вода 19л × 5 шт.
     💰 Наличные | 75 000 сум
     ⏰ Создан: 10 минут назад
     
     [✅ Взять заказ #127]
     
     ───────────────────────
     
     #128 | Петров П.П.
     📍 ул. Регистан, 8
     🚰 Вода 19л × 3 шт.
     💳 Карта | 45 000 сум
     ⏰ Создан: 25 минут назад
     
     [✅ Взять заказ #128]
```

**Ограничения:**
- ❌ Нет фильтров (только все заказы)
- ❌ Нет карты с геопозицией
- ❌ Нет сортировки по расстоянию
- ✅ Можно взять заказ одной кнопкой

**Вердикт:** ✅ **ВОЗМОЖНО** (базовая версия без карты)


## 4. Рекомендуемая архитектура: Гибридный подход

### Вариант 1: **Только кнопки** (MVP)
**Плюсы:**
- ✅ Не требует HTTPS
- ✅ Не требует сборки фронтенда
- ✅ Работает на любом устройстве
- ✅ Быстрая разработка (1-2 дня)

**Минусы:**
- ❌ Нет карты с геопозицией
- ❌ Нет красивого каталога с фото
- ❌ Неудобно для многопозиционных заказов

**Когда использовать:** Для быстрого запуска, тестирования бизнес-процессов

### Вариант 2: **Гибрид (кнопки + Mini App)** ⭐ РЕКОМЕНДУЕТСЯ
**Архитектура:**
```
Курьер:
├── Кнопки (основное):
│   ├── Открыть/закрыть смену
│   ├── Начать/закрыть рейс

│   ├── Подтвердить доставку
│   ├── Статистика рейса

│

    ├── Пул заказов с картой

    └── Графики статистики

Клиент:
├── Кнопки (основное):
│   ├── Регистрация
│   ├── Заказ 1 товара (быстрый заказ)
│   ├── История заказов
│   └── Уведомления
│

    ├── Каталог с фото
```
